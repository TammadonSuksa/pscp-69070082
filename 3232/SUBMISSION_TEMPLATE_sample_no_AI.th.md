# บันทึกการแก้โจทย์

ไฟล์นี้เป็นตัวอย่าง ห้ามคัดลอกเนื้อหานี้ไปใช้เป็น submission ของตนเอง

ใช้ไฟล์นี้เพื่อดูระดับรายละเอียดที่คาดหวังเท่านั้น

ตัวอย่างนี้แสดงโจทย์ง่าย ๆ ที่ไม่ได้ใช้ AI

ตัวอย่างนี้ยังแสดงวิธีเปิดเผยความช่วยเหลือเล็กน้อยจากคนด้วย เนื่องจากไม่ได้ใช้ AI นักศึกษาไม่ต้องทำ `ai_reflection.md`

## 1. ข้อมูล OJ

```text
OJ3232 - [LEARNING LOGS] กบน้อยกระโดด
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
611632
```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
15-30 minutes
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่นๆ

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
กบกระโดดครั้งเเรกได้ X เมตร เเละจะลดลงครั้งละ 2 เรื่อยๆจาก X จนกว่าจะถึง Y ถ้าไปถึง ให้ตอบว่ากบต้องกระโดดกี่ครั้ง ถ้่าไม่ถึงให้ตอบ -1

Input:
กระโดดครั้งเเรก X เมตร
เป้าหมายระยะทาง Y เมตร

Output:
จำนวนครั้งที่กบต้องกระโดดไปถึง Y เมตร คือกระโดดกี่ครั้ง ถ้าไปไม่ถึงให้ตอบ -1

Constraints:
ต้องเขียนเงื่อนไข ถ้ากระโดดไปถึงระยะ Y เมตรพอดีต้องออกลูป เพื่อกันไม่ให้จำนวนกระโดดครั้งมันเกิน
```

---

## 3. แผนแรกของฉัน

```text
Step 1: รับค่า X เเละ ค่า Y มาก่อน
Step 2: เข้าลูปให้กระต่ายกระโดดครั้งเเรก X เมตร เเละลดครั้งละ 2 เมตรลงไปเรื่อยๆต่อการกระโดดครั้งต่อไป 
Step 3: ถ้าลูปเรื่อยๆเเล้วระยะทาง X น้อยกว่า 0 เเล้วก็ให้ออกลูปเลย
Step 4: เช็คเงื่อนไขว่ากบกระโดดถึงตามเป้าหมาย Y เมตรมั้ย ถ้าถึงให้ตอบจำนวนการกระโดดว่าต้องกระโดดกี่ครั้ง ถ้าไม่ถึงให้ตอบ -1
```

---

## 4. วิธีสุดท้ายที่ใช้จริง

```text
เหมือนวิธีเเรกเลยเเต่จะเขียนโค้ดเพิ่มไปส่วนนึงคือ ให้ออกลูปเมื่อกระโดดจนครบ Y เมตรเเล้วก็ให้ออกลูปได้เลย ไม่ต้องให้มันวิ่งจน X น้อยกว่าเท่ากับ 0
```

## 5. การทดสอบของฉัน

## 6. การใช้ AI

ใช้ AI กับโจทย์นี้หรือไม่

```text
No
```

ถ้าใช้ AI ต้องทำไฟล์นี้ด้วย:

```text
ai_reflection.md
```

ถ้าถามเฉพาะเพื่อน TA หรือผู้สอน และไม่ได้ใช้ AI ไม่ต้องทำ `ai_reflection.md`
