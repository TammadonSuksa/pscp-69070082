## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้จำนวนรอบมา n รอบ จากนั้นก็ input ถ้าเป็น + ให้เพิ่ม 10 คะเเนน ถ้าเป็นลบ ให้ลบ 10 คะเเนน

Input:
จำนวนเต็ม n
บรรทัดที่สองถึง n บรรทัด พิมพ์ + หรือ -

Output:
จำนวนเต็มที่เอาไป บวก 10 หรือ ลบ 5 รวมกันทั้งหมด

Constraints:
ต้องลูปจำนวน input ตามจำนวน n
```

---

## 3. แผนแรกของฉัน

```text
Step 1: รับค่าจำนวนเต็ม n
Step 2: ลูปจำนวน n เเล้วรับ input จำนวน n รอบ
Step 3: ถ้าเป็น + เพิ่ม 10 คะเเนน ถ้าเป็น - ลบ 5 คะเเนน
Step 4: เเสดงผลจำนวนรวมหลังจากทำครบจำนวนรอบ
```
