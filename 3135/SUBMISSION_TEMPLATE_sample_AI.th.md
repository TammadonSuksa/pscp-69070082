## 2. ความเข้าใจโจทย์ของฉัน

```text
โจทย์ให้หาว่าที่กี่คนที่ได้ตรวจสอบของขวัญ โดยเอาของขวัญให้เริ่มตั้งเเต่คนเเรก เเล้วให้คนถัดไปโดยโจทย์กำหนดว่าต้องให้ เดินไปกี่ครั้ง จากนั้น พอถึงคนที่กำหนดเเล้ว จะมีสองเงื่อนไข ถ้าวนกลับมาคนเเรกก็ให้หยุดการวนทันที เเต่ถ้าวนไปโดนขโมย ก็คือให้นับขโมยด้วยจากนั้นก็หยุดลูปทันที จากนั้นให้เเสดงผล จำนวนคนที่ได้รับการพิจารณาของขัญ

Input:
บรรทัดเดียว : จำนวนคน n จำนวนส่งต่อ k ขโมยนคนที่ t

Output:
จำนวนคนที่ได้รับพิจารณาของขวัญ

Constraints:
มันสามารถวนรอบได้เรื่อยๆ จนกว่าจะเป็นคนที่ 1 หรือคนที่ t
```

---

## 3. แผนแรกของฉัน

```text
Step 1: รับค่าทั้งสามค่ามาก่อน N K T
Step 2: ใช้ while loop ในการวนไปเรื่อยๆ
Step 3: หาจำนวนที่เราข้ามไปในเเต่ละรอบ โดยคิดเผื่อถ้าเราเดินวนรอบ 1 รอบด้วยโดยการใช้ mod ในการหาจำนวนที่มันเกินออกไปก่อน ก็คือ exact position ที่เราได้วนไปเเล้วอยู๋ตำเเหน่งนั้นจริงๆ โดยใช้สูตร position = (position + k) % n
Step 4: เมื่อได้ exact position มาเเล้วให้เข้าเงื่อนไข ถ้ามัน == 1 หรือว่าถ้า position == t ให้หยุดการทำงานลูปได้เลย
Step 5: เก็บค่า check เเต่ละรอบ ให้ บวก 1 ทุกรอบใต้ล่างเงื่อนไข position == 1
```

## 4. วิธีสุดท้ายที่ใช้จริง

```text
วิธีสุดท้ายไม่ต่างจากวิธีเเรกมาก ต้องเขียนต่างไปน้อย ต้องให้มัน ลบ ค่า position ออกไปนึงก่อน เพราะ เราเริ่มคนที่ตำเเหน่ง หนึ่ง ถ้า ตำเเหน่งที่เราอยู่ บวกกันกับ k เเล้ว mod n มันจะได้ = 0 ซึ่งตำเเหน่ง 0 ไม่มีอยู๋จริง ต้องลบ ค่า 1 ไปก่อน เเล้วค่อยกลับมาบวกที่หลังตอนเอาไป mod n
```
