## 4. AI ช่วยให้ฉันสังเกตอะไร

อธิบายแนวคิด ข้อผิดพลาด bug edge case หรือ concept ที่ AI ช่วยให้สังเกต

```text
AI ช่วยให้ฉันสังเกตุว่าถ้าการทำโจทย์ที่ตัวเลขอาจจะเป็นตัวเลขที่ใหญ่ๆหรือเยอะมากๆเนี่ย ถ้าใช้ While loop ในการคำนวณเสมอไปอาจจะทำให้เกิด Timeout ได้ จึงควรสังเกตุ Pattern หรือมุมมอง หรือการคิดสมการอื่นเเทน เพื่อในการทำให้โค้ด มีประสิทธิภาพเเละลดเรื่องของ Time Complexity ไปได้
```

## 5. ฉันตรวจสอบหรือแก้อะไรด้วยตนเอง

อธิบายว่าก่อนส่งเข้า OJ คุณตรวจสอบ ทดสอบ แก้ไข หรือตัดสินใจอะไรด้วยตนเอง

ตัวอย่าง:

- ฉันทดสอบ case เพิ่มเติมใน VS Code
- ฉันตรวจ input/output format
- ฉันเปรียบเทียบคำแนะนำของ AI กับ problem statement ใน OJ
- ฉันแก้ code หลังจากเข้าใจ bug แล้ว
- ฉันไม่ใช้บางส่วนของคำแนะนำจาก AI เพราะไม่ตรงกับโจทย์

```text
ฉันได้สังเกตเห็นรูปเเบบว่า ไอที่ฉันคำนวณไปก่อนหน้านี้อ่ะ มันใช้เเทนกันได้ ไม่ต้องคำนวณซ้ำ (นั้นก็คือรัศมีระยะห่างระหว่าง 0,0 กับพิกัดบ้านของฉัน กับ พิกัดที่ค่อยๆเดินทางไปตั้งเเต่ 0,0 ไปถึง พิกัดบ้านมันสามารถใช้ซ้ำได้ หรือก็คือฉันคิดซ้ำเเล้วคิดให้มากยากเอง)
ฉันเลยได้เเก้ไขด้วยคำใบ้จากโจทย์ที่บอกใช้หลักคำนวณทั่วไปเลย คือการ เอา พื้นที่ทั้งหมด(หรือระยะทางทั้งหมด) หาร อัตราความเร็ว จะได้เท่ากับวินาทีออกมา เปลี่ยนวิธีที่คิดหลายรอบมาคิดเเค่รอบเดียว
```

## 6. ฉันได้เรียนรู้อะไร

เขียน 2-4 ประโยคเกี่ยวกับสิ่งที่ได้เรียนรู้จากโจทย์นี้และจากการใช้ AI

ให้เน้นการเรียนรู้ของตนเอง ไม่ใช่แค่คำตอบสุดท้าย

```text
ฉันได้เรียนรู้ว่าโจทย์พวกนี้ไม่จำเป็นต้องใช้ While loop เสมอไป ไม่จำเป็นต้องสร้างตัวเเปรอะไรเยอะเเยะไม่จำเป็น เราจำเป็นต้องสังเกตรูปเเบบเเละมีความเข้าใจพื้นฐานทางคณิตศาสตร์อยู่พอสมควร จะทำให้สามารถเข้าใจเเละนำสูตรต่างๆมาประยุกต์ใช้ได้ ไม่จำเป็นต้องเขียนมันตรงๆเสมอไป
```
