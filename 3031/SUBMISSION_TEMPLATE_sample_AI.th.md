## 2. ความเข้าใจโจทย์ของฉัน

```text
โจทย์ให้คำนวณหาว่า จุดที่น้ำหมึกค่อยๆกระจายจากจุด (0,0) จะกระจายขยายไปถึงบ้านที่พิกัด (x,y) ในวินาทีที่เท่าไร

Input:
บรรทัดเเรก อัตราพื้นที่ของน้ำหมึกที่ขยายต่อหนึ่งวินาที (จำนวนเต็ม) , จำนวนคำร้องจากผู้คน (จำนวนเต็ม)
n บรรทัด (ตามจำนวนคำร้องของผู้คน) เป็นพิกัด (x , y)

Output:
n บรรทัด จำนวนวินาทีที่น้ำหมึกขยายไปถึงที่จุดของเเต่ละบ้าน ถ้าเป็นทศนิยมให้ปัดขึ้น

Constraints:
จำนวนรัศมีที่ไม่เท่ากันในการขยายพื้นที่เเต่ละรอบ ถ้าเป็นตำเเหน่งที่ไกลมากๆจะคำนวณเยอะมากๆจนทำให้ Timeout จึงจำเป็นต้องทำวิธีอื่น
```

## 3. แผนแรกของฉัน

```text
เเผนเเรกของฉันใช้วิธีการหาวิทีละตัว โดยคำนวณสูตรทุกรอบที่พื้นที่เปลี่ยน ก็จะคำนวณรัศมีใหม่ เเล้วเอาไปลบกับอันก่อน พอลบเสร็จก็เอาไปบวก เป็นระยะทางรวม

Step 1: รับค่า อัตราน้ำหมึกขยายต่อวินาที กับ คำร้องขอมา เเละก็สร้างค่าอัตราคงที่ของ อัตราน้ำหมึกขยายต่อวินาทีขึ้นมาเพื่อเอาไปบวกเพิ่มขึ้นในทุกๆรอบของวินาทีที่มีการเปลี่ยนเเปลง
Step 2: หาระยะทางของบ้านเรากับจุด 0,0
Step 3: พอได้มาเเล้วต่อไปจะหาจำนวนวินาทีว่าเราต้องใช้กี่วินาทีในการเดินทางไปถึงบ้านของเรา
Step 4: ใช้วิธี while loop เช็คเรื่อยๆ เพิ่มระยะทาง กับ วินาทีเรื่อยๆ จนกว่า ระยะทางรวมของเราที่เดินตั้งเเต่จุด 0,0 มันมากกว่า จุดระยะทางของบ้านเรากับจุด 0,0 ก็ให้ยกเลิก while loop 
Step 5: เมื่อจบ loop รอบนึงของคำร้องขอของคนๆนึงก็ให้ทำการ print วินาทีที่เก็บใว้ในตัวเเปรนึงขึ้นมา
```

## 4. วิธีสุดท้ายที่ใช้จริง

```text
วิธีสุดท้ายต่างออกไปก็คือ ไม่จำเป็นต้องหาวนลูปทีละรอบ ในเมื่อที่เราคำนวณตอนเเรก มันคือรัศมีที่ถ้าถึงรัศมีตรงนี้เเล้วน้ำหมึกก็จะโดนบ้านเรา มันหาได้จากสูตรเราอยู่เเล้ว เเละในเมื่อเรามี อัตราน้ำหมึกที่ขยายต่อวินาทีอยู่เเล้วก็เอาไอรัศมีตรงนั้นไปคำนวณหาพื้นที่ทั้งหมด พอได้พื้นที่ทั้งหมดเเล้ว ก็ไปหารกับ อัตราน้ำหมึกที่ขยายต่อวินาที ก็จะได้วินาทีที่เมื่อน้ำหมึกขยายไปถึงบ้านเราพอดี
วิธีนี้ช่วยตัดปัญหาในการเกิด Timeout ในเงื่อนไขที่ input เป็นเลขที่เยอะมากๆ
```
