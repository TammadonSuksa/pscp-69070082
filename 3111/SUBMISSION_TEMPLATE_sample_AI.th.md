## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้รับ input มาว่าเป็นสมาชิกมั้ย กับ จะซื้อของกี่ชิ้น ถ้าเป็นสมาชิก จะลด 5% จากยอดรวมสินค้าทั้งหมด ถ้าไม่เป็นสมาชิก เเต่ซื้อของยอดรวมตั้งเเต่ 500 ขึ้นไปจะลดราคา 3% จากนั้นให้เเสดงยอดสุทธิ ด้วยทศนิยม 2 ตำเเหน่ง ปัดเศษตามมาตรฐาน round half up

Input:
บรรทัดที่ 1 : ระบุว่าเป็นสมาชิกมั้ย Y/N (เป็น string)
บรรทัดที่ 2 : จำนวนรายการที่ซื้อ n (เป็น int)
บรรทัดที่ 2+n : ราคาสินค้าจำนวน n บรรทัด เป็นจำนวนจริง

Output:
ยอดสุทธิหลังจากคำนวณส่วนลดทั้งหมดเเล้ว (ทศนิยม 2 ตำเเหน่ง ปัดเศษมาตรฐาน round half up)

Constraints:
ข้อนี้ความยากคือเราไม่สามารถเเสดงทศนิยมสองตำเเหน่งที่ปัดเศษเเบบ round half up ได้ เพราะใน string format :.2f ที่เราใช้บ่อยๆมันปัดเศษตามหลัก banker round ทำให้มีข้อจำกัดการกำหนดหลักการปัดเศษที่ค่อนข้างยาก
```

## 3. แผนแรกของฉัน

```text
Step 1: รับค่า input ว่าเป็นสมาชิกมั้ย (Y/N) เเละรับค่าจำนวนสินค้า (integer) สร้างตัวเเปรใหผลรวมสินค้าทั้งหมด = 0
Step 2: เขียนเงื่อนไขถ้า เป็นสมาชิกลด 5% ถ้าไม่เป็นสมาชิกเเต่ซื้อของมากกว่า 500 บาท ลด 3%
Step 3: ให้เเสดงเงื่อนไขออกมาด้วยวิธีที่ใช้ half round up เอาผลรวมราคาาทั้งหมด * 100 + 0.5 จากนั้นเอาไปหาร 100 เเล้วให้เเสดงออกเป็นทศนิยม 
```

## 4. วิธีสุดท้ายที่ใช้จริง

```text
Logic if else เเบบวิธีเเรกเลย เเต่ต่างกันที่เก็บตัวเเปรของผลรวมราคาเเละการเเสดงผลให้ทศนิยม 2 ตำเเหน่งให้เป็นในรูปเเบบของ round half up โดยวิธีเก็บ โดยใช้เป็น decimal เเทน float เลย เพราะค่า decimal จะมีความเเม่นยำมากกว่า float 
ให้เก็บตัวเเปรผลรวของราคาเป็น decimal เเละค่าที่เอาไปบวกหรือคูณทุกค่าในเงื่อนไข ให้นำไปเเปลงเป็น decimal ทุกค่า จากนั้นให้เเสดงผล print โดยที่กำหนดรูปเเบบเป็นทศนิยมสองตำเเหน่งเเละกำหนด การ rounding เป็น round half up

```
