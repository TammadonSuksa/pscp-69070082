## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้ Input เดือน เเละ วันที่ไป เเล้วก็เเต่ละเดือน จะมีฤดูของมัน ซึ่งในโจทย์ใบ้มาว่า ทุกวันที่ 21 ขึ้นไป เเละ เดือนที่ หาร 3 ลงตัว ก็คือ mod 3 == 0 จะเป็นฤดูถัดไปโดยอัตโนมัติเลย

Input:
เดือน (Integer)
วันที่ (Integer)

Output:
ชื่อฤดู ตามที่โจทย์กำหนด (spring,summer,fall,winter)

Constraints:
ข้อนี้มันไม่ได้เปลี่ยนฤดูตอนขึ้นเดือนใหม่ เเต่เปลี่ยนฤดูตอนวันที่ 21 ของเดือนที่ 3 หารลงตัวก็เลยทำให้ต้องมีการเขียนเงื่อนไขเล็กๆน้อยๆเข้ามาเพื่อเเก้ไขในส่วนนี้
```

---

## 3. แผนแรกของฉัน

```text
Step 1: รับ input เดือนกับวันที่มาก่อน
Step 2: กำหนดเเต่ละฤดูให้เเทนตัวเลข โดยการ เดือน / 3 (เพราะ ทุก 3 เดือนจะเป็น 1 ฤดู)
Step 3: สร้างเงื่อนไข ถ้ามันอยู่ในเดือนที่ mod 3 == 0 เเละ day >= 21 (ตั้งเเต่วันที่ 21 ขึ้นไป) ให้เปลี่ยนฤดูที่เราอยู่ ก็คือ เลื่อนไปหนึ่งครั้งก็คือ บวกด้วยหนึ่ง
Step 4: ถ้าเลขฤดูมันตรงกับอะไรก็ให้เป็นฤดูนั้นเเล้ว print ออกมา
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายเหมือนกับวิธีเเรก เเต่ต้องมีการดักเงือนไขอีกอย่างก็คือ ถ้ามันเป็นเดือน 4 เเล้วบวก 1 มันจะเป็น 5 ซึ่งเรามี 4 ฤดูเราก็จะเพิ่มเงื่อนไขเข้าไปก่อนที่จะเลื่อน ใส่ else ไป
```
