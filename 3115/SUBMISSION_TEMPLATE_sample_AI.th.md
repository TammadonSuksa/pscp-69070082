## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้ input ค่า เวลาเปิดเวลาปิดของเเต่ละร้าน จากนั้น ก็ input อีกตัวคือเวลาที่เราเดินออกไปดูเเต่ละร้าน เเล้วให้ดูเวลาในช่วงเวลาที่เราเดินอ่ะ มีจำนวนกี่ร้านที่ยังเปิดอยู่

Input:
บรรทัด 1: จำนวน num เเละจำนวน check ว่ามีร้านกี่ร้านเเละเราเดินเช็คกี่ครั้ง
บรรทัด num + 1: เวลาร้านเปิดตั้งเเต่ 0 - 1440 เเละเวลาร้านปิด ตั้งเเต่ 0 - 1440 โดยที่ เวลาร้านปิด > เวลาร้านเปิด
บรรทัดที่ (num + 1) + check: เวลาที่เราเดินไปในเเต่ละรอบ

Output:
จำนวนร้านที่เปิดอยู่ในเวลานั้นๆ โดยพิมพ์บรรทัดเดียว

Constraints:
จำนวนเช็คร้านในเเต่ละรอบต้องหาเก็บไว้เป็นบรรทัดเดียว
```

## 3. แผนแรกของฉัน

```text
Step 1: รับ input จำนวนร้าน เเละ จำนวนที่เดินเช็คเเต่ละรอบมาก่อน
Step 2: สร้าง dict เก็บค่าช่วงเวลาที่ร้านเปิดเอาไว้
Step 3: วนลูปเก็บค่าเข้า เวลาเปิดเเละปิดร้านไว้ใน dict ในเเต่ละรอบของจำนวนร้าน
Step 4: รับจำนวนเวลาที่เราเดินในเเต่ละรอบเก็บไว้ใน List
Step 5: ให้ลูปตามจำนวนที่เราเดินเช็คเเต่ละรอบ
Step 6: สร้างเงื่อนไข ให้เอา List ที่เก็บไว้รอบเเรก ไปเทียบกับ dict เเต่ละตัว ว่าเวลาที่เราเดินมันมากกว่า เเละ น้อยกว่าเวลาที่ร้านเปิดปิดมั้ย
Step 7: เก็บจำนวน count ในเเต่ละรอบที่เดิมไว้ใน List
```
