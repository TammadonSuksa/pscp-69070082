## 2. ความเข้าใจโจทย์ของฉัน

```text
โจทย์ให้คะเเนนรวมของทั้ง 3 คนมาก่อน เเละให้คะเเนนที่สูงที่สุดของทั้ง 3 คนนั้นมา เราต้องหาว่าถ้ามันมีความเป็นไปได้ว่า เลขของคนที่สูงที่สุด ห่างกับคนที่เลขน้อยที่สุดมากกว่า 2 จะทำให้ output เป็น Surprising เเต่ถ้าไม่ ก็จะเป็น Not surprising 

Input:
คะเเนนรวมของทั้งสามคน (Float)
คะเเนนของคนที่คะเเนนมากที่สุด (Float)

Output:
Surprising , Not surprising (String)

Constraints:
ความต่างของคะเเนนบาง Test case มันไม่ได้เป็น Integer เเต่มันเป็น Float
```

## 3. แผนแรกของฉัน

```text
ผมใช้วิธีในการ บวกเเต่ละเลข ซึ่งค่าตรงกลางมันจะต้องมากกว่าเลขที่ต่ำกว่าเสมอ ผมเลยให้ค่า middle บวก 2 ก่อนจากนั้นค่อยบวกทีละ 1 ค่า low บวกทีละ 1 
Step 1: หาว่ายังเหลืออีกเท่าไร ถึงจะครบจำนวนรวมทั้งสามคน
Step 2: สร้างตัวเเปร count ขึ้นมาเพื่อวนลูปในการบวกเลขสองตัว ใช้ในเงื่อนไข count < remain ก้ยังคงบวกต่อไป
Step 3: ตามที่ได้กล่าวไป ค่ากลางจะต้องมากกว่า ค่าต่ำสุด ก็เลยให้เริ่มเเรกค่ากลางบวก 2 ค่าต่ำสุดบวกไป 1 ก่อนในรอบเเรก
Step 4: เมื่อได้ค่าที่ต่างกันมากที่สุดที่จะเป็นไปได้ เเล้วโดยค่ากลางจะต้องมากกว่าค่าต่ำสุดอยู่เสมอ จากนั้นให้หาผลต่างของ ค่ามากที่สุดกับค่าที่ต่ำที่สุด
Step 5: เข้าเงื่อนไขเปรียบเทียบถ้าห่างมากกว่า 2 จะเป็น Surprising น้อยกว่าเป็น Not surprising
```

## 4. วิธีสุดท้ายที่ใช้จริง


```text
ต่างจากเเผนที่ใช้ตอนเเรกคือสร้างตัวเเปร count มาให้นับเพิ่มขึ้นทีละ 1 เพื่อหาค่าที่ต่างกันมากที่สุด เเละ ค่ามันคือระหว่าง 0-10 เป็น float ด้วยซึ่งไม่สามารถคำนวณตัวเลขที่น้อยได้ ในเเผนสุดท้ายผมก็เลยในเมื่อค่าที่ต่างที่สุดสามารถทำได้โดยการให้ค่ากลางมันเท่ากับค่าที่สูงที่สุด จากนั้น เอาผลรวมทั้งสามคน - ผลรวมทั้งสองคนก็จะได้เหตุการณ์คนที่ได้น้อยที่สุด จากนั้นเอาไปเทียบในเงื่อนไขเหมือนเดิม
เเละก็ได้เพิ่มในส่วนของเงื่อนไข error ไว้ด้วยโดยการใส่ได้ไว้ด้านบนสุดของโค้ด

```
