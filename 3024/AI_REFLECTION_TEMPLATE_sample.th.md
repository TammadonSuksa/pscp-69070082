## 3. ฉันถาม AI ให้ช่วยอะไร

อธิบายสั้น ๆ ว่าถาม AI ให้ช่วยเรื่องอะไร

ห้ามวาง chat log ทั้งหมด

ตัวอย่าง:

- ฉันถาม AI ให้ช่วยอธิบายโจทย์
- ฉันถาม AI ให้ช่วย review แผนแรกของฉัน
- ฉันถาม AI ให้ช่วยหา bug ใน code
- ฉันถาม AI ให้ช่วยเสนอ test cases
- ฉันถาม AI ให้อธิบายว่าทำไมผล OJ จึงผิด

```text
ฉันถาม AI ว่า ที่โค้ดฉันไม่ผ่าน เพราะโจทย์ให้รับเป็น Float ใช่มั้ย เเล้วตอนเเรกที่ฉันเขียนเป็น count += 1 อ่ะ มันไม่สามารถคำนวณตัวเลขที่มันละเอียดกว่านี้ได้ เลยทำให้บางเทสเคสไม่ผ่านใช่มั้ย
```

## 4. AI ช่วยให้ฉันสังเกตอะไร

อธิบายแนวคิด ข้อผิดพลาด bug edge case หรือ concept ที่ AI ช่วยให้สังเกต

```text
AI ช่วยให้ฉันสังเกตุว่า วิธีที่ง่ายกว่าการเอาเลขมาบวกทีละตัวเพื่อหาค่าที่เเตกต่างกันมากที่สุดอ่ะมันมีวิธีที่ง่ายกว่านั่น มันให้ฉันคิดว่า เลขกลา
งคือเลขที่ไม่เกินค่าที่มากที่สุด เเละไม่ต่ำกว่าค่าที่น้อยที่สุด มันก็เลย ให้ค่ากลางของฉันเท่ากับค่าที่มากสุดไปเลย จากนั้นก็จะสามารถหาเหตุการณ์ที่ค่าที่น้อยที่สุดได้ง่ายเเละเร็วกว่าเดิม
```

## 5. ฉันตรวจสอบหรือแก้อะไรด้วยตนเอง

อธิบายว่าก่อนส่งเข้า OJ คุณตรวจสอบ ทดสอบ แก้ไข หรือตัดสินใจอะไรด้วยตนเอง

ตัวอย่าง:

- ฉันทดสอบ case เพิ่มเติมใน VS Code
- ฉันตรวจ input/output format
- ฉันเปรียบเทียบคำแนะนำของ AI กับ problem statement ใน OJ
- ฉันแก้ code หลังจากเข้าใจ bug แล้ว
- ฉันไม่ใช้บางส่วนของคำแนะนำจาก AI เพราะไม่ตรงกับโจทย์

```text
ก่อนที่ฉันจะส่งฉันได้ทดลองเลขที่เป็นทศนิยมดูว่าจะสามารถคำนวณออกมาได้มั้ย เเละมันสามารถคำนวณเลขได้ละเอียดกว่า การที่ฉันเอาตัวเเปร count มาบวกทีละหนึ่งเเบบนี้ เเละฉันได้ลองเขียนสมการที่มันยกตัวอย่างหรือใบ้มาให้ด้วยตัวเองจนทำให้ผ่านทุก Testcase
```

## 6. ฉันได้เรียนรู้อะไร

เขียน 2-4 ประโยคเกี่ยวกับสิ่งที่ได้เรียนรู้จากโจทย์นี้และจากการใช้ AI

ให้เน้นการเรียนรู้ของตนเอง ไม่ใช่แค่คำตอบสุดท้าย

```text
ฉันได้เรียนรู้ว่าการเขียนโค้ดมันไม่จำเป็นต้องเขียนไปตรงๆโดยเสมอ เราต้องเข้าใจภาพรวมเเละมุมมองหลายๆมุมมอง ว่าทำเเบบไหนสามารถได้ง่ายกว่า หรือเอามุมมองที่เรามองตอนเเรกมาประยุกต์ยังไงให้กลายเป็นมุมมองอื่นได้ เเละได้ฝึกการตั้งสมการด้วยตัวเองว่าเขียนยังไง ถึงจะสั้นเข้าใจง่ายมากที่สุดเเละไม่ใช้ตัวเเปรซ้ำซ้อน
```
