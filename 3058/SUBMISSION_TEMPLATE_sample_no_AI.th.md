## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ ให้อิฐมาสองก้อน ก้อน a ยาว 1 นิ้ว ก้อน b ยาว 5 นิ้ว ต้องใช้ ก้อน b ให้ได้มากที่สุดก่อน จากนั้นถึงจะค่อยใช้ก้อน a ถ้าก้อน a รวมกับก้อน b เเล้วไม่พอ ให้ output ออกมาเป็น -1 เเต้ถ้าพอ ให้ output ออกมาเป็นจำนวน brick ก้อน a ที่ได้ใช้ไป

Input:
Brick ก้อน a เป็นจำนวนเต็ม
Brick ก้อน b เป็นจำนวนเต็ม
จำนวนเป้าหมาย goal เป็นจำนวนเต็ม

Output:
จำนวน brick a อย่างน้อยที่สุด ถ้าใช้ brick a เเล้วไม่สามารถสร้างได้ให้ตอบ -1

Constraints:
ต้องคำนวณว่าอย่างน้อยที่สุดของ brick b ต้องใช้กี่ก้อน เเละต้องคำนวณให้มันไม่เกินจำนวนเป้าหมาย (goal)
```

## 3. แผนแรกของฉัน

```text
เเผนเเรกของผมไม่ค่อยดีมากเพราะเขียนซ้ำซ้อนเกินไป
Step 1: รับ input a , b , goal เป็นจำนวนเต็มมาก่อน
Step 2: สร้างกรณีเเยก กรณีที่ brick b น้อยกว่า goal กับ brick b มากกว่า goal
Step 3: กรณี brick b น้อยกว่า ให้หา ค่า คงเหลือมาก่อน เพราะยังไงเราต้องใช้ brick ทั้งหมดอยุ่เเล้ว เเล้วหาว่ายังจต้องเหลืออีกเท่าไร จากนั้น ถ้า brick a มันน้อยกว่าค่าคงเหลือ ให้ตอบ -1 ทันที ถ้ามากกว่า ให้ตอบตามจำนวนที่ยังต้องการ
Step 4: กรณี brick b มากกว่า ให้เอาค่า brick b ที่เรามีทั้งหมดลบ goal จากนั้นเอาค่าที่ได้ไปหาร 5 เเล้วกลับไปคูณ 5 จะได้คงเหลือมา a น้อยกว่า remain เป็น -1 ถ้ามากกว่า ถ้ามากกว่าให้ตอบตามจำนวนที่ต้องการ

```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้าย ต่างจากวิธีเเรกมาก ไม่ต้องคิดเยอะซ้ำซ้อน 
ใช้วิธี หาจำนวนที่ brick b ใช้ได้ก่อน คือเอา goal ไป floor division 5 เมื่อได้จำนวน brick b ที่เราสามารถใช้ได้เเล้ว ถ้า brick b มากกว่าหรือ = ค่า maxb ที่เราเอาไปหารตอนเเรก ให้เอา maxb * 5 เลย ถ้า brick b น้อยกว้่า maxb ให้ maxb = brickb * 5 เพื่อให้ได้ตามจำนวน จากนั้นหาค่าคงเหลือ ว่าต้องใช้ brick a อีกเท่าไรถึงจะถึง goal ถ้า brick a น้อยกว่า remain ให้ตอบ -1 ถ้ามากกว่า ให้ตอบ ตามจำนวน คงเหลือ
```
