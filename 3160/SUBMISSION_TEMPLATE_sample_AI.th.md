# บันทึกการแก้โจทย์

ไฟล์นี้เป็นตัวอย่าง ห้ามคัดลอกเนื้อหานี้ไปใช้เป็น submission ของตนเอง

ใช้ไฟล์นี้เพื่อดูระดับรายละเอียดที่คาดหวังเท่านั้น

ตัวอย่างนี้แสดงโจทย์ที่มี input/output หลายบรรทัด และมีการใช้ AI

เนื่องจากมีการใช้ AI นักศึกษาต้องทำไฟล์ `ai_reflection.md` ด้วย

---

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3160 - [LEARNING LOGS] หาจำนวนเฉพาะ
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
639456
```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
30-60 minute
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
ให้ใส่ input range ของตัวเลขมา เช่น 1 10 เเล้วให้หาว่าในช่วงของเลขนั้นอ่ะ มีกี่ตัวที่เป็น prime number หรือจำนวนเฉพาะ

Input:
จำนวนเริ่มต้นเเละจำนวนสุดท้าย

Output:
จำนวน Prime number ว่ามีตัวเลขอะไรบ้าง
จำนวน Prime number ว่ามีทั้งหมดกี่ตัว

Constraints:
ข้อจำกัดข้อนี้คือ ไม่มีสูตรลับ วิธีคิดเเบบคณิตศาสตร์ ต้องใช้วิธีการลูปหาตัวเลขที่ละตัว ถ้ามัน mod เเล้วไม่ได้ 0 ทุกตัว เเสดงว่าเป็น Prime number
```

## 3. แผนแรกของฉัน

```text
Step 1: รับจำนวนเลขที่อยากรู้มาก็คือ จุดเริ่มต้น เเละ จุดสิ้นสุด
Step 2: ให้ลูปตัวที่อยู๋ในช่วงทีละตัวมาก่อน เเล้วเอาไปหารเอาเศษตั้งเเต่ 2 ถึงตัวมันเองโดยใช้ลูปซ้อนลูป
Step 3: ถ้ามันเจอตัวที่หารเอาเศษลงตัวหรือได้ 0 เเสดงว่าไม่ใช่จำนวนเฉพาะ
Step 4: ถ้ามันไม่ลงตัวสักตัวเลยเเสดงว่าเป็นจำนวนเฉพาะ ให้ยัดลง List ที่เก็บไว้เฉพาะตัวที่เป็นจำนวนเฉพาะ
Step 5: ถ้านับจำนวนเฉพาะได้มากกว่า 0 ให้เเสดง ตัวจำนวนเฉพาะทีละตัวโดยใช้ List comprehension ลูปออกมาทีละตัว เเล้วใช้ .join เพื่อ join ช่องว่างที่ขั้นระหว่าง
```

## 5. การทดสอบของฉัน

เขียน test cases อย่างน้อย 3 กรณีที่ลองเองหรือออกแบบเอง

พยายามเลือก test cases ที่แตกต่างกัน

แต่ละ test case ให้อธิบายว่าทำไมเลือกกรณีนั้น

ถ้า input หรือ output มีหลายบรรทัด ให้เขียนไว้ใน text blocks

### Test Case 1

ทำไมเลือก case นี้:

```text
กรณีที่เป็นเลข 2 เพราะเลข 2 คือจำนวนเฉพาะ
```

Input:

```text
1 2
```

Expected output:

```text
2
Total primes: 1
```

Actual output:

```text
2
Total primes: 1
```

Result:

```text
Pass
```

### Test Case 2

ทำไมเลือก case นี้:

```text
ตรวจสอบถ้าตัวเลขมากๆช่วงมากๆจะเป็นยังไงเพราะมันลูปซ้อนลูปซึ่งจะใช้เวลาเยอะมากอาจจะทำให้ Timeout ได้
```

Input:

```text
1 100000
```

Expected output:

```text
Timeout โค้ดระเบิด
```

Actual output:

```text
Timeout โค้ดระเบิดจริงๆ
```

Result:

```text
Pass
```

### Test Case 3

ทำไมเลือก case นี้:

```text
ถ้าเป็นช่วงที่ตัวเลขติดลบโค้ดจะหาได้มั้ย
```

Input:

```text
-20 2
```

Expected output:

```text
2
Total primes: 1
```

Actual output:

```text
2
Total primes: 1
```

Result:

```text
Pass
```

## 6. การใช้ AI

ใช้ AI กับโจทย์นี้หรือไม่

```text
Yes
``` 

ถ้าใช้ AI ต้องทำไฟล์นี้ด้วย:

```text
ai_reflection.md
```

ถ้าถามเฉพาะเพื่อน TA หรือผู้สอน และไม่ได้ใช้ AI ไม่ต้องทำ `ai_reflection.md`

## 8. คำรับรองของนักศึกษา

เขียน `Yes` ในแต่ละ statement

| Statement | Yes/No |
|---|---|
| I wrote this submission in my own words. | Yes |
| I understand my final code. | Yes |
| I recorded the real OJ status. | Yes |
| I did not copy AI-generated text directly into this file. | Yes |
| I did not copy code from another person. | Yes |
| If I received human help, I disclosed it in this file. | Yes |
| I submitted the final code to the OJ by myself. | Yes |
