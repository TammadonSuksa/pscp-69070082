## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้รับค่าจุดเริ่มต้น กับจุดหมายปลายทางเป็น string เเละค่าน้ำหนักของพัสดุเป็น float มา จากนั้นเช็คเงื่อนไขตามตาราง ถ้าเข้าเงื่อนไข ให้ดูว่า ค่าธรรมเนียมเริ่มต้นเท่าไร เเล้วค่าเนียมน้ำหนักกี่บาท (คิดเป็นบาทต่อกิโลกรัม) จากนั้นให้เเสดง output ค่าธรรมเนียมรวมทั้งหมดเป็นทศนิยมสองหลัก ถ้าจุดเริ่มต้น กับจุดหมายปลายทางไม่มีตรงตามเงื่อนไขในตารางให้เเสดงเป็น Error

Input:
บรรทัดที่ 1 : จุดเริ่มต้น กับจุดหมายปลายทาง (เป็น string)
บรรทัดที่ 2 : น้ำหนักของพัสดุ (เป็น float)

Output:
ค่าธรรมเนียมรวมทั้งหมดในการส่งพัสดุ (ทศนิยม 2 หลัก) 
ถ้าไม่เข้าเงื่อนไขในตารางให้เเสดง Error

Constraints:
จุดเริ่มต้น กับปลายทาง ต้องเข้าเเค่เงื่อนไขในตารางเท่านั้นถึงจะคำนวณได้
```

---

## 3. แผนแรกของฉัน

```text
Step 1: รับค่า input จุดเริ่มต้น จุดหมายปลายทางเป็น string เเล้วก็น้ำหนักเป็น float
Step 2: เอาจุดเริ่มต้น กับ จุดหมายปลายมางเทียบในตาราง ถ้ามี ให้คำนวณ
Step 3: วิธีคำนวณ เอาค่าธรรมเนียม + (weight*ค่าธรรมเนียมน้ำหนักบาทต่อกิโลกรัม)
Step 4: เเสดงผลออกมาเป็นทศนิยม 2 ตำเเหน่ง

ถ้าไม่เข้าเงื่อนไขใดใน Step 2 ให้ทำการเเสดงผล Error
```
