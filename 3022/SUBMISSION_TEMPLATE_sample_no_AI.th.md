## 2. ความเข้าใจโจทย์ของฉัน

```text
โจทย์ให้อุณหภูมิเป็นหน่วยๆนึงมา เเละต้องเเปลงจากหน่วยนึงไปอีกหน่วยนึงตามสูตรที่โจทย์ได้ให้มา

Input:
อุณหภูมิ (Float)
Unit of this temp (String)
Transfer Unit to (String)

Output:
อุณหภูมิที่เเปลงมาเเล้ว (Float 2 ตำเเหน่ง)

Constraints:
ต้องเเปลงอุณหภูมิไปมา เเล้วมองสมการอาจจะงงหรือสับสนได้
```

---

## 3. แผนแรกของฉัน

```text
Step 1: รับค่า input มาก่อน คืออุณหภูมิ เเละอุณหภูมิที่เราจะเเปลง
Step 2: ให้สร้างเงื่อนไขซ้อนเงื่อนไข เงื่อนไขด้านนอกจะเป็นตัวที่เช็ค unit ของเราก่อน เงื่อนไขด้านในคือเช็ค transfer unit ที่เราจะเเปลงไปเป็นอะไร
Step 3: คำนวณตามสูตรที่โจทย์ได้ให้มา 
Step 4: เเสดง output เป็น float โดยให้เป็นทศนิยมม 2 ตำเเหน่ง
```

## 4. วิธีสุดท้ายที่ใช้จริง

```text
เหมือนกับวิธีเเรกเลยเเต่เเตกต่างจากเดิมนิดหน่อย โดยลดเงื่อนไขที่ใช้ไปตอนเเรก ปกติจะต้องเช็คเงื่อนไขเเบบซ้อนเงื่อนไขใช่มั้ย เเต่ทีนี้มันติด PEP-8 เรื่องของ Too many branch เลยทำให้ต้องลดโค้ดมาโดยใช้ Logic ในการ ให้เเปลงค่า C เป็นค่าตั้งต้นเลย ตั้งเเต่เเรก เเล้วก็เช็คเงื่อนไข ของ Transfer Unit ว่าเป็นอะไร จากนั้นก็เอาตัวเเปร C ที่เราไว้เป็นค่าตั้งต้นไปคำนวณเก็บไว้ในตัวเเปร result เเล้ว print ออกมาเป็นทศนิยม 2 ตำเเหน่งเลย จะเร็วกว่า เเละไม่ติดเรื่องของ PEP-8
```
